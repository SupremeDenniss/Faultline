# Roadmap

1. **Foundation (Phase 1, implemented):** local CloudTrail normalization, two deterministic rules, SQLite incidents, CLI, synthetic demo, tests, and CI.
2. **Detection and correlation (planned):** broader event rules, time windows, related-event grouping, and rule versioning.
3. **AWS infrastructure (planned):** EventBridge ingestion, deployment definitions, and DynamoDB adapter.
4. **Incident response (planned):** controlled response workflows, approvals, and audit trails.
5. **Monitoring and reliability (planned):** operational metrics, retries, dead-letter handling, and health checks.
6. **Advanced detection (planned):** richer temporal and identity context with explainable evidence.
7. **Dashboard (planned):** incident review and investigation interface.
8. **Production hardening (planned):** security review, scale testing, access control, and operational runbooks.
